# DNS Doctor — OpenClaw plugin

Email-deliverability diagnosis for OpenClaw agents: scan a domain's SPF/DMARC/DKIM/MX,
get validated fix records (never AI-composed), and hand off to continuous monitoring.

**First release lands shortly** — the plugin is in final review.

- Site: https://dnsdoctor.dev
- Methodology: https://dnsdoctor.dev/methodology
- MCP endpoint: `https://dnsdoctor.dev/mcp`
